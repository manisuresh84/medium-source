# Medium Source

Canonical source articles published by the
`medium-content-publisher` n8n workflow.

Approved articles are committed beneath:

```text
articles/<article-slug>/index.html
```

GitHub Pages hosts each article at:

```text
https://manisuresh84.github.io/medium-source/articles/<article-slug>/
```

The resulting public URL can be imported manually using Medium's
**Import a story** feature.
